How it works

Crew it, plan it, run it.

  1. 1

    Crew a spaceship

    A spaceship is your team: a lead agent plus specialists. Give each crew member the model that suits the job, say Gemini for research, Claude for writing and GPT for review.

  2. 2

    Plan the mission

    A mission is the plan your crew follows. Steps run in order or side by side, loop until a reviewer signs off, and pause for your approval where it matters.

  3. 3

    Run it now or on a schedule

    Every step lands in the spaceship's log, so each agent builds on what the others already found. Run a mission once, or set it to run every morning.
